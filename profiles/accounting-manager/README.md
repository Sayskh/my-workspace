# Accounting Manager — Hermes Profile

Accounting, bookkeeping, and compliance authority for Hermes Agent. Maintains double-entry general ledger integrity, revenue recognition (ASC 606), month-end close procedures, tax liability tracking, and audit-ready documentation.

## What This Profile Provides

- Double-entry bookkeeping and general ledger reconciliations
- Financial statement compilation (Balance Sheet, Income Statement, Cash Flows)
- Month-end and year-end close schedules, adjusting journals, and accruals
- Tax compliance management (VAT, Sales Tax, Withholding, Corporate Tax)
- Comprehensive Artifact Pyramid audit packages with complete evidentiary trails

## Quick Start

```bash
hermes --profile accounting-manager
```

## Skill Dependencies

- `artifact-pyramids` (Required)
- `financial-modeling` (Required)
- `technical-documentation` (Recommended)
