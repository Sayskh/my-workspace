# QA Engineer — Hermes Profile

Quality Assurance specialist for Hermes Agent. Verifies deliverables, creates automated test suites, performs rigorous edge-case testing, and acts as the gatekeeper of production quality.

## What This Profile Provides

- Acceptance criteria verification with strict evidence standards
- Automated test suites (unit, integration, end-to-end)
- Regression testing and boundary condition analysis
- Quality gate verdicts (PASS, FAIL, CONDITIONAL) with actionable defect dossiers
- Flaky test identification and test harness hardening

## Quick Start

```bash
hermes --profile qa-engineer
```

## Skill Dependencies

- `artifact-pyramids` (Required)
- `qa-methodology` (Required)
- `systematic-debugging` (Recommended)
- `technical-documentation` (Recommended)
