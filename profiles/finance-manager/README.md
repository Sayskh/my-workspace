# Finance Manager — Hermes Profile

Operational financial management specialist for Hermes Agent. Manages day-to-day budgets, operational expenditures, vendor contracts, cash flow projections, and team cost centers.

## What This Profile Provides

- Operating budget tracking and monthly variance analysis
- Operational expense approvals within delegated authority
- Vendor invoice verification, renewal management, and contractor disbursements
- Rolling 90-day operational cash flow forecasting
- Departmental cost center monitoring and budget compliance

## Quick Start

```bash
hermes --profile finance-manager
```

## Skill Dependencies

- `artifact-pyramids` (Required)
- `financial-modeling` (Required)
- `startup-analysis` (Recommended)
