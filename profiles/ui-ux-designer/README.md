# UI/UX Designer — Hermes Profile

UI/UX design specialist for Hermes Agent. Crafts intuitive user journeys, wireframes, component design systems, style tokens, and accessible interaction patterns.

## What This Profile Provides

- Information architecture and user flow design
- Design systems, color palettes, typography hierarchies, and token definitions
- Usability heuristic evaluations and friction point audits
- WCAG AA accessibility compliance criteria and touch target specifications
- Comprehensive Artifact Pyramid design briefs for frontend implementation

## Quick Start

```bash
hermes --profile ui-ux-designer
```

## Skill Dependencies

- `artifact-pyramids` (Required)
- `ux-methodology` (Required)
- `mermaid-diagrams` (Recommended)
