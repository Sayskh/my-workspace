# CFO — Hermes Profile

Chief Financial Officer specialization for Hermes Agent. Owns financial strategy, capital allocation, cash runway, unit economics, budget enforcement, and financial scenario modeling.

## What This Profile Provides

- Capital discipline and runway protection
- Financial scenario modeling (Base, Upside, Downside)
- Unit economics evaluation (CAC, LTV, Gross Margins, Payback Period)
- Budgeting and capital expenditure approval frameworks
- Cost of capital and risk-adjusted return analysis

## Quick Start

```bash
hermes --profile cfo
```

- `financial-modeling` (Required)
- `executive-methodology` (Required)
