# Repo Manager — Hermes Profile

Repository governance and release management specialist for Hermes Agent. Enforces Git hygiene, branch protection rules, semantic versioning (SemVer), automated changelog generation, and PR merge integrity.

## What This Profile Provides

- Semantic versioning, release tagging, and release notes compilation
- Automated changelog generation based on Conventional Commits
- PR merge readiness auditing (linear history, clean rebasing, CI status)
- Branch protection policies, CODEOWNERS definitions, and repository hygiene
- Git conflict resolution strategies preserving commit integrity

## Quick Start

```bash
hermes --profile repo-manager
```

## Skill Dependencies

- `artifact-pyramids` (Required)
- `technical-documentation` (Required)
- `implementation-planning` (Recommended)
