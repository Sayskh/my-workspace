# Financial Analyst — Hermes Profile

Financial Analyst & FinOps specialist for Hermes Agent. Provides data-driven financial intelligence, analyzes cloud compute costs, benchmarks SaaS metrics (NRR, CAC Payback, Rule of 40), and builds multi-scenario financial forecast models.

## What This Profile Provides

- FinOps cloud infrastructure cost optimization (AWS/GCP/Azure/bare-metal)
- SaaS metric calculations (ARR, MRR, Net Revenue Retention, CAC Payback)
- Cohort churn analysis and expansion revenue modeling
- Multi-variable financial sensitivity models and Monte Carlo projections
- Industry peer benchmarking and SaaS valuation multiple tracking

## Quick Start

```bash
hermes --profile financial-analyst
```
