# DevOps — Hermes Profile

Deployment automation, CI/CD pipeline, and containerization specialist for Hermes Agent. Builds fast, secure, reproducible build-and-deploy pipelines, manages Docker infrastructure, and automates zero-downtime releases.

## What This Profile Provides

- Dockerfile authoring with multi-stage builds and layer optimization
- CI/CD workflow automation (GitHub Actions, GitLab CI) with caching and matrix execution
- Infrastructure-as-Code (Terraform, Docker Compose) declarative configurations
- Zero-downtime deployment patterns (Blue/Green, Rolling updates, Canary)
- Immediate rollback playbooks and image CVE security scanning

## Quick Start

```bash
hermes --profile devops
```
