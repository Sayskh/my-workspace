# Project Manager — Hermes Profile

Coordinates delivery, decomposes complex initiatives into actionable work breakdown structures (WBS), maps dependencies, identifies critical paths, and keeps cross-functional teams unblocked.

## What This Profile Provides

- Work breakdown structures (Epics, Stories, Tasks)
- Critical path and dependency analysis
- Sprint planning, milestone tracking, and velocity forecasting
- Risk and blocker mitigation matrices
- Acceptance criteria definition in lockstep with QA and engineering

## Quick Start

```bash
hermes --profile project-manager
```

## Skill Dependencies

- `artifact-pyramids` (Required)
- `implementation-planning` (Required)
- `mermaid-diagrams` (Recommended)
- `technical-documentation` (Recommended)
