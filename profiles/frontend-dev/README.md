# Frontend Dev — Hermes Profile

Frontend engineering specialist for Hermes Agent. Implements responsive, accessible, resilient client interfaces, manages frontend state, optimizes Core Web Vitals, and integrates cleanly with APIs.

## What This Profile Provides

- Production-grade UI component and page implementation
- Responsive design across mobile, tablet, and desktop
- Accessible interaction (WCAG AA compliance, ARIA, keyboard navigation)
- Client-side data fetching, caching, optimistic mutations, and robust error boundaries
- Artifact pyramid handoffs with component architecture and visual verification

## Quick Start

```bash
hermes --profile frontend-dev
```

## Skill Dependencies

- `artifact-pyramids` (Required)
- `ux-methodology` (Required)
- `systematic-debugging` (Recommended)
- `mermaid-diagrams` (Recommended)
